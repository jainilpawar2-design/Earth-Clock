#  Real-Time Earth Clock

A beautiful interactive 3D Earth simulation built with **Three.js** that displays the real-time day/night cycle, world clock, and location marker on Earth.

![GitHub](https://img.shields.io/badge/HTML-5-orange)
![GitHub](https://img.shields.io/badge/JavaScript-ES6-yellow)
![GitHub](https://img.shields.io/badge/Three.js-r128-blue)
![GitHub](https://img.shields.io/badge/License-MIT-green)

---
##  Features

-  Interactive 3D Earth
-  Real satellite-style Earth textures
-  Real-time day & night simulation
-  Moon orbit animation
-  Animated star field
-  Select locations around the world
-  Live world clock
-  Adjustable simulation speed
-  Mouse drag to rotate Earth
-  Scroll to zoom

##  Installation

### Clone the repository

```bash
git clone https://github.com/jainilpawar2-design/Earth-Clock.git
```

Open the project folder

```bash
cd Earth-Clock
```

Simply open

```
index.html
```

in your browser.

No installation required.

---

##  Deploy on GitHub Pages

1. Upload the project to GitHub.
2. Make sure the homepage is named:

```
index.html
```

3. Go to

```
Settings
→ Pages
```

4. Select

```
Deploy from a branch
```

5. Choose

```
Branch: main
Folder: / (root)
```

6. Save.

Your website will be available at

```
https://YOUR_USERNAME.github.io/earth-clock/
```
